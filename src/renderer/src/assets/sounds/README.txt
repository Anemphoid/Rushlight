Rushlight's branded sounds live here. Drop the files in with these base
names (any of .wav / .flac / .mp3 / .ogg works):

  self-join      you enter a room
  self-leave     you leave (plays at half volume)
  other-join     someone else enters the room you're in
  other-leave    someone else leaves the room you're in
  room-switch    you move from one room to another
  ptt-on         push-to-talk pressed   (used once voice is connected)
  ptt-off        push-to-talk released  (used once voice is connected)

A missing file just means that sound stays silent. Nothing breaks.
